# 音乐检索系统 (Query By Singing/Humming)

本项目为《信号与系统》课程大作业——“基于哼唱片段的音乐检索系统（听歌识曲）”。

## 任务目标

- **基础1**：提取一段简单单音音频的基频（如使用自相关法），生成音高序列。
- **基础2**：给定一小段标准乐谱序列，通过DTW等算法计算哼唱片段与标准序列的相似度。
- **进阶**：建立包含至少10首歌的小型曲库，实现输入哼唱音频并返回最匹配的歌曲。
- **挑战**：提高算法对不同人哼唱（跑调、节奏不准）的容错率，或尝试带伴奏的旋律识别；包装为一个可演示的Demo。

## 数据集说明

本项目在算法开发与评估过程中，使用了 [MIRLab 公开数据集](http://mirlab.org/dataset/public/)。

### 1. 核心数据集：MIR-QBSH
- **说明**：QBSH 是 Query By Singing/Humming 的行业标准缩写。该数据集是国际音乐信息检索评测比赛（MIREX）多年的官方测试集。
- **应用场景**：
  - **对口基础1**：适合单声道音高追踪（Monophonic pitch tracking）与静音/清音/浊音检测，是测试基频提取算法抗噪能力的绝佳素材。
  - **对口基础2 & 进阶**：自带标准答案（Ground Truth / MIDI 序列），可用其直接构建10首歌的小型标准曲库；同时提供大量真实的、带有偏差的人类哼唱样本（WAV 音频），非常适合用来严谨测试 DTW 算法的容错率。

### 2. 挑战备单数据集：MIR-1K (选做)
- **说明**：帮助冲击大作业最高难度——“带伴奏的旋律识别”。
- **应用场景**：音频中包含伴奏。侧重于人声分离 (Singing voice separation) 和音频旋律提取。运行前需先使用分离模型（如 Spleeter）把伴奏与人声剥离，再将被丢入算基频的函数中。

## 当前开发进度与成果

目前已经完美实现了**基础1**、**基础2** 以及**进阶**部分的核心功能。以下是各核心模块与函数的功能拆解：

### 1. 单帧基频提取模块 (`extract_pitch.py`)
- **`extract_pitch(frame, fs, window)`**：
  - **核心原理**：基于短时自相关法（Autocorrelation），通过计算音频帧与自身的延迟相关性来寻找周期律。
  - **频段限制**：限定搜索范围在 50Hz (极低音) 到 1000Hz (极高音) 之间，有效过滤环境低频噪音与高频谐波干扰。
  - **加窗处理**：支持 Hamming 或 Blackman 窗，消除截断信号的边缘效应与频谱泄漏。

### 2. 全局音频序列处理模块 (`process_audio.py`)
- **`get_pitch_contour(audio_path, sr, frame_samples, hop_samples, energy_threshold)`**：
  - **时域对齐**：为匹配 MIR-QBSH 数据集标准，将采样率锁定为 8000Hz、步长精确控制为 256 采样点。
  - **静音识别与剔除 (VAD)**：基于 `librosa.feature.rms` 求取每帧短时能量。对于均方根能量低于设定的阈值的帧直接置 0（判定为休止符或呼吸杂音），避免自相关算法在噪声中盲目搜索。
  - **平滑去噪滤波**：引入 `scipy.signal.medfilt`，使用 `kernel_size=5` 的中值滤波对非静音段进行平滑。该操作成功抹平了自相关倍频误判导致的“突刺”，极大提升了基频轨迹的鲁棒性。

### 3. 音高序列比对模块 (`dtw_compare.py`)
- **`calculate_similarity(seq1, seq2, remove_silence)`**：
  - **静音帧抛断**：在比对前过滤掉 `0` 所在的静音帧，确保仅针对有效旋律走势进行特征计算。
  - **零均值归一化 (Zero-Mean Normalization)**：这是本系统**高容错率的核心**。通过将哼唱序列和 MIDI 序列分别减去各自的平均音高，消除了人类演唱时的整体调性偏移（跑调）和男女声的八度差异，使 DTW 只比较相对起伏。
  - **动态时间规整算法 (DTW)**：利用动态重对齐解决人类哼唱过程中的拖拍、抢拍问题，最终返回路径归一化后的平均最小距离得分。

### 4. 系统整合与评测脚本 (`demo.py`)
- **`load_pv_file(pv_path)` 与 `get_midi_contour(midi_path)`**：分别处理了 `.pv` 标注文件（支持不同格式Hz到MIDI的自适应转换），并将离散事件的 `.mid` 乐谱按步长平铺展开为时间序列特征。
- **高精度验证体系 (`main`)**：
  - 构建了严格与宽容（容许倍频与八度误差的 `< 1.0` 半音级）两种准确率评估体系，使系统的帧级音高提取准确率达到了 **97.03%**。
  - 在小型曲库检索任务中，成功通过最小 DTW 距离将原曲 (`00020.mid`) 精准筛选并排名至第一。
